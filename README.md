# codsoft_password-generator
Password Generator

**Description**

This is a simple Password Generator application developed using Python. The program generates a strong and random password based on the length specified by the user. It uses a combination of uppercase letters, lowercase letters, numbers, and special characters to create secure passwords.

---

**Features**
- Generate random passwords
- User can specify the password length
- Includes letters, digits, and special characters
- Easy to use and beginner-friendly
- Helps create strong passwords for better security

**Technologies Used**
- Python 3
- Random Module
- String Module

**How to Run**

1. Install Python 3 on your system.
2. Save the program as "password_generator.py".
3. Open a terminal or command prompt.
4. Navigate to the project folder.
5. Run the program using:

python password_generator.py

---

**Usage**

1. Enter the desired password length.
2. The program generates a random password.
3. The generated password is displayed on the screen.

**Example**

---


Enter password length: 10

Generated Password: A@7kP#9mQ$

**Code Explanation**
- "string.ascii_letters" provides uppercase and lowercase letters.
- "string.digits" provides numbers from 0 to 9.
- "string.punctuation" provides special characters.
- "random.choice()" selects random characters from the character set.
- The loop generates a password of the specified length.

**Learning Outcomes**

This project helps beginners understand:

- User input handling
- Python loops
- String manipulation
- Random number generation
- Using built-in Python modules
